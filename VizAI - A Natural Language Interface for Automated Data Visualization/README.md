***** VizAI : A Natural Language Interface for Automated Data Visualization (Final Year Team Project) *****

Overview of the Project :
- VizAI is a web-based system designed to simplify data visualization through natural language queries. 
- It leverages the power of Large Language Models (LLMs), specifically LLaMA-3, to interpret user intent and generate insightful visualizations from structured datasets. 
- Users can interact with the system simply by typing queries in their natural language as convenient to them and VizAI will process the request and return the appropriate chart (visualization).
- By bridging the gap between technical complexity and user-friendly design, VizAI democratizes access to data-driven decision-making.

Requirements of the Project :
- Operating System : macOS Sonoma (14.5)
- Programming Language : Python
- Python Version : 3.11
- Visualization Libraries : Matplotlib, Seaborn
- NLP & LLM Integration : LLaMA-3
- Web Framework : Flask
- Frontend Technologies : HTML, CSS, JavaScript, Jinja2 templating
- IDE : Visual Studio Code
- Tested On : Mac Mini (Apple M2, 16GB RAM, 256GB SSD)


Features of the Project :
- Accepts CSV file uploads.
- Understands natural language queries.
- Generates various chart types :
  - Bar Chart
  - Line Chart
  - Pie Chart
  - Histogram
  - Scatter Plot
  - Box Plot
- Offers real-time feedback for incorrect/ambiguous queries.
- Customizable chart options.

Steps for Implementation :
- Download the Source Code of the Project / Clone this repository.
- Run app.py file in the IDE to view the output.
